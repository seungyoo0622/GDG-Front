# 이번주에 배운 내용

## HTML의 개념
+ HTML의 창시자
    + 팀 버너스리
* HyperText + MarkupLanguage
    * MarkupLanguage란 텍스트 이외의 정보를 전달하는 언어

## HTML의 기초적인 사용법
+ 다양한 태그들
    + h1(heading 1), h2(heading 2), p(paragraph), title 등등
* 하이퍼텍스트 사용법
    * a href
- 스크립트 사용법
    - console.log, alert

## 웹 문서라는 개념
+ 웹 문서는 거미줄로 연결된 정보의 묶음이다
* HTML도 웹 문서
