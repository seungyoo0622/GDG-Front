# 이번 주에 배운 내용

## DOM의 개념
+ 기존 개발 방식의 문제점
    + HTML 코드가 길어지면 다수의 개발자가 협업하기 어려움
* DOM
    * Document Object Model
    * HTML 태그 하나하나를 자바스크립트로 컨트롤할 수 있도록 만든 객체 체계
    * 트리 구조

## React의 개념
+ 부품화
    + JS파일을 부품처럼 사용하여 효율을 높임

* JSX
    * Javascript Syntax eXtension
    * JS 코드에 HTML 태그를 넣어 작성할 수 있게 해주는 확장팩

- Babel
    - JSX 코드를 원래의 JS 코드로 바꿔주는 컴파일러
    - JSX에 동봉됨

## React의 기본적인 사용법
+ npx create-react-app [파일명]
    + npm을 통해 react를 하기 위해 필요한 파일을 받아옴
    + npm start

## 기타 
+ 컴포넌트의 함수,파일명은 대문자로 시작
* export default를 사용하여 다른 파일에서도 import할 수 있게 함
