# 이번 주에 배운 내용

## React의 탄생
+ 페이스북의 서버 비용 문제
    + 일부 변경에도 전체 문서를 주고받아 비효율적
* 부품화 (컴포넌트)
    * SPA의 여러 기능을 쉽게 관리하고자 HTML을 부품처럼 분리
- Virtual DOM
    - 잦은 실제 DOM 조작은 브라우저에 과부하 유발
    - 가상의 DOM에서 미리 조작 후 결과만 일괄 반영

## React Hook과 Props
+ useState
    + 일반 변수는 값이 변해도 화면이 업데이트되지 않음
    + React가 상태 변화를 감지하도록 Hook 사용
        + const [count, setCount] = useState(0);
* Props
    * 상위 컴포넌트의 state를 하위 컴포넌트로 전달하는 값
    * 상위 state 변경 시 하위 컴포넌트도 새롭게 리렌더링

## 컴포넌트의 생애주기 (Lifecycle)
+ 생애주기 3단계
    + 1. Mount (탄생) : 화면에 나타남
    + 2. Update (변화) : props나 state 변경으로 리렌더링
    + 3. UnMount (죽음) : 화면에서 사라짐

## 클래스형 vs 함수형 컴포넌트
+ 클래스형 컴포넌트
    + 장점 : 정형화된 패턴으로 협업 유리, 세밀한 생애주기 조절
    + 단점 : 문법이 복잡하고 학습 난이도가 매우 높음
* 함수형 컴포넌트와 Hook
    * 과거엔 state 사용이 불가능한 반쪽짜리였음
        * React 16.8부터 Hook 도입
        * 코드가 직관적이며 모든 Hook은 'use'로 시작
